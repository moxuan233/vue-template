# 第三方数据来源与许可

## 1. 六十四卦文本语料（主要数据源）

- 项目：**qingshano/yijing-data** — 易经六十四卦结构化数据集
- 地址：https://github.com/qingshano/yijing-data
- 许可：**MIT License**（见同目录 `yijing-data-LICENSE.txt`，Copyright (c) 2026 guan）
- 本项目使用的内容：
  - `data/index.json` — 卦序、卦名、卦全名、八宫归属、六位爻画、上下卦
  - `data/relations.json` — 互卦 / 错卦 / 综卦 的 ID 映射
  - `data/hexagrams/NN.json` — 每卦的卦辞、彖传、大象传、六爻爻辞与小象传
- 用途：`src/data/yijing.generated.ts`（由 `tools/gen_yijing_ts.py` 生成），
  以及 `src/data/hexagrams.ts` 中由爻画派生的形状工具。

本项目对该语料做了以下**校验**（见 `tools/verify_yijing_data.py`），未改动其文本结构：

1. 64 卦爻画唯一，且每卦上下卦与爻画前/后三位一致；
2. 384 爻的爻题阴阳与卦画逐一吻合，爻辞、小象均非空；
3. 八宫各 8 卦、合计 64 卦；
4. 互卦、错卦、综卦与三者的数学定义（二至四/三至五互体、六爻尽变、六爻倒转）逐一吻合。

**校勘**：语料存在个别字形讹误，本项目依通行本《周易》改正，且**只改字形、不动句式与标点**。
全部修正列在 `tools/gen_yijing_ts.py` 的 `ERRATA` 表中（含讹字、正字与依据），可逐条回查。
当前共三处：

| 位置 | 语料原作 | 改正 | 依据 |
| --- | --- | --- | --- |
| 《乾》九二 | 见龙**再**田 | 见龙**在**田 | 通行本作「见龙在田」 |
| 《屯》六三 | **既**鹿无虞 | **即**鹿无虞 | 通行本作「即鹿无虞」，《周易正义》释「即」为追逐 |
| 《旅》六二、九三 | 童**仆** | 童**僕** | 简繁混字，此处义为僮仆 |


## 2. 解卦方法论（讲义性内容，非数据）

`src/logic/reader.ts` 的"解卦十一步"、`src/views/MethodView.vue` 的方法说明，
取材于《周易》原书中的《系辞上》《系辞下》《说卦》及书前《读〈易〉需要了解的一些基本术语》
（中译出版社／中华书局 2011 年杨天才、张善文译注本扫描件）。这些是公有领域的古籍原文与
术语体系，本项目只做归纳与编排。

## 3. 本项目自建内容（非第三方）

以下内容源书与语料均未提供，属本项目实现，界面上已明确标注，请勿误当作原书内容：

- **五行、十神、藏干、纳音、空亡、命宫、胎元**等四柱（子平）体系的排盘与标注；
- **纳甲（月体纳甲天干配卦）**用于"八字起卦"的映射规则，及"日干 + 时支定动爻"的取法；
- **六亲、六神**等后世筮法的六爻属性标注；
- **八宫世应位置**的推导表（归属与次序已与上述语料的 `gongName` 逐条核对一致）。
